Uma data exporter

A small tool for
your Uma data.

umadump reads available game data and writes JSON files for compatible community tools. Run it once for a snapshot, or leave daemon mode open to update files while you play.

Quick start

Four steps, then use your data.

  1. 01

    Download

    Put the latest release in the folder where you want output files; extract it first if needed.

  2. 02

    Launch

    Open Uma, then start umadump.exe.

  3. 03

    Snapshot or daemon

    For a snapshot, let the first pass finish. To keep exports current, type d at the prompt and leave the console open.

  4. 04

    Use the JSON

    Files are written relative to where you started umadump. Open a compatible export in the community tool you want to use.
