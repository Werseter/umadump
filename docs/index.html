Easy by default

Download it.
Run it your way.

No installer or setup marathon. Unzip the release, start umadump alongside the game, and choose a quick export or a hands-off watcher.

  1. 01

    Download & run

    No installation required. Unzip the latest release and launch umadump when the game is open.

  2. 02

    Export once

    Need a quick snapshot? Run it once; umadump writes the available data and exits.

  3. 03

    Keep it watching

    Daemon mode stays running in the background, checks the live game at intervals, and writes updated outputs while you play. Stop it whenever you like.
